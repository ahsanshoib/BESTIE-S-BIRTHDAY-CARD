# 🎂 Bestie's Birthday Card

A lightweight, interactive, and fully responsive web application created to celebrate a special birthday with animations, audio effects, and personal messages.

Live Demo: https://bestie-birthday-card.vercel.app
---

## ✨ Features

- *Interactive Timeline & Animations:* Smooth visual steps including candle blowing dynamics and celebrations.
- *Background Music & Sound Effects:* Audio integration for clapping effects and dedicated birthday tunes.
- *Photographic Gallery & Notes:* Dynamic text and visual presentations.
- *Mobile Responsive:* Works seamlessly across all desktop and mobile browsers.

---

## 🛠️ Built With

- *HTML5* - Structure
- *CSS3* - Custom styling and animations
- *JavaScript (Vanilla)* - DOM manipulation and audio logic
